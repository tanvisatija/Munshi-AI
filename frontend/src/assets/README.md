# Brand assets

Drop these three files here (exact names). They are picked up automatically on the next
build; until then the app uses a built-in fallback mark.

- `munshi_ai_logo.svg`: circular icon mark (preferred, rendered inline so it stays crisp)
- `munshi_ai_logo.png`: same mark as a PNG fallback
- `munshi_ai_wordmark.png`: icon + "Munshi AI" lockup, used in the top header bar
